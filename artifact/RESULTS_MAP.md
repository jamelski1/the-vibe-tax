# Paper result → script that regenerates it

Every script resolves its data paths relative to this folder, so run them from the `artifact/`
directory. Scripts marked **[tests]** need the HF-gated `lcb_tests.jsonl` (see README "What is NOT
included"); everything else runs from the shipped data with no gated tests.

| Paper result | Regenerated by | Needs tests? | Notes |
|---|---|---|---|
| **Compile-rate by condition**, all four extractors (Fig. 1a; the terse→detailed naive asymmetry; ours flat at 100%; LCB reversed) | `python mechanism_table.py` (naive/ours/sanitize) and `extractors.py` self-test; full 4-extractor compile table also in `The_Vibe_Tax_Three_Extractors.ipynb` | no | computed from stored replies only |
| **Mechanism table** (median reply length, % with prose, naive SyntaxError counts by condition) | `python mechanism_table.py` | no | — |
| **Paired compile-rate McNemar**, terse vs detailed (naive 73/24 p=6.4e-7; ours 0/0; sanitize 12/21) | `python mechanism_table.py` | no | — |

| **Paired pass-rate McNemar + discordant counts**, terse vs detailed, per extractor (naive 78/25 p=1.6e-7; ours 13/13 p=1.0; sanitize 16/24 p=0.27) | `LCB_TESTS=… python score_all_extractors.py` | **[tests]** | — |

## End-to-end, from raw replies

1. (optional, to regenerate pass-rates) build tests: `python extract_lcb_tests.py` → `lcb_tests.jsonl` **[needs HF access]**
2. compile-level results, mechanism, encoding audit, offline McNemar, figures: run the "no" rows above — **no tests needed**.
3. pass-rate + McNemar table: `LCB_TESTS=lcb_tests.jsonl python score_all_extractors.py`.
